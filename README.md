# تاكسي العاصمة | Taxi Capital

منصة عربية لطلب وإدارة الرحلات، تبدأ من شمال سيناء وقابلة للتوسع.

## التطبيقات
- `apps/customer`: واجهة العميل.
- `apps/driver`: بوابة السائق.
- `apps/admin`: لوحة الإدارة.
- `packages/shared`: الأنواع المشتركة.
- `functions`: منطق الخادم الموثوق.

## التقنية
Next.js + TypeScript + Turborepo + Firebase (Auth / Firestore / Cloud Functions).

## التشغيل
يتطلب Node.js 20 أو أحدث:
```bash
npm install
npm run dev
```

## إعداد الخدمات
انسخ `.env.example` إلى ملفات البيئة المحلية وأضف إعدادات Firebase والخرائط من لوحات المزودين. لا ترفع الأسرار أو مفاتيح الإنتاج إلى Git.

## تنبيه
هذه بداية المشروع وبنيته الأساسية، وليست منصة إنتاج مكتملة. لم يتم ربط Firebase أو الخرائط أو تفعيل توزيع الرحلات بعد.
