# تفعيل نسخة تاكسي العاصمة المطوّرة

هذا الدليل خاص بفرع `work/complete-platform-admin`. التعديلات محفوظة في GitHub ولم يتم نشرها على الموقع الحي أو تغيير بيانات Firebase.

## ما أُضيف في هذا الفرع

- لوحة إدارة عربية مرتبطة بـ Firebase، مع تحقق من `users/{uid}.role == "admin"`.
- متابعة السائقين والرحلات والعملاء ودفتر الحسابات.
- اعتماد السائقين وضبط تعريفة المدينة والخدمة والعمولة.
- إنشاء ملف العميل تلقائيًا عند أول تسجيل دخول Google، دون استبدال دور حساب موجود.
- خريطة السائق ومشاركة موقعه فقط أثناء الاتصال أو تنفيذ رحلة.
- عرض موقع السائق للعميل داخل الرحلة المسندة إليه فقط، عبر مجموعة `tripDriverLocations`.
- إكمال الرحلة بحساب المسافة الفعلية من Google Routes API على الخادم.
- توزيع مرحلي لعروض السائقين ضمن نطاقات 5 ثم 12 ثم 25 كم، مع انتهاء العرض بعد 60 ثانية وإغلاق الطلب عند استنفاد المراحل.

## إعدادات مطلوبة قبل النشر

### 1. إعداد متغيرات بناء لوحة الإدارة

لوحة الإدارة تستخدم حزمة Firebase المشتركة. داخل Cloud Shell، ومن جذر المشروع، أنشئ ملف البيئة المحلي من إعداد العميل الموجود:

```bash
cp apps/customer/.env.local apps/admin/.env.local
chmod 600 apps/admin/.env.local
```

لا ترفع ملفات `.env.local` إلى GitHub ولا تشارك قيمها في المحادثات.

### 2. تفعيل Google Routes API وCloud Scheduler

```bash
gcloud services enable routes.googleapis.com cloudscheduler.googleapis.com --project taxi-alasema-app-2026
```

يجب أن يكون Google Routes API مفعّلًا مع إعداد الفوترة في مشروع Google Cloud.

### 3. إضافة مفتاح خادم منفصل

أنشئ مفتاحًا منفصلًا لاستخدام الخادم فقط، وقيّده بـ Routes API مع حدود استخدام مناسبة. لا تستخدم مفتاح المتصفح المقيّد بمواقع الويب لهذا الغرض.

```bash
firebase functions:secrets:set GOOGLE_MAPS_SERVER_API_KEY --project taxi-alasema-app-2026
```

أدخل المفتاح في المطالبة التفاعلية داخل Cloud Shell فقط. لا تلصقه في ملف مصدر أو GitHub أو محادثة.

### 4. التحقق من حساب الإدارة

يجب أن يحتوي مستند المدير في `users/{uid}` على الحقل:

```json
{ "role": "admin" }
```

يُضبط هذا الحقل من مسار إداري موثوق فقط، وليس من واجهة العميل. لا تمنح هذا الدور لأي حساب غير موثوق.

## أوامر البناء والنشر

نفّذ البناء أولًا:

```bash
npm install
npm run build
npm --prefix functions run build
```

بعد مراجعة النتائج والموافقة على نشر الوظائف:

```bash
firebase deploy --only functions --project taxi-alasema-app-2026
```

قواعد Firestore لها نشر مستقل، ولا تنشرها إلا بعد مراجعة التغييرات:

```bash
firebase deploy --only firestore:rules --project taxi-alasema-app-2026
```

واستضافة الموقع لها نشر مستقل كذلك. لا تستخدم `firebase deploy` العام؛ حتى لا تنشر خدمات أو قواعد أخرى دون قصد.

## ملاحظات تشغيلية

- وظائف الرحلات وموقع السائق واحتساب المسافة تتطلب App Check صالحًا.
- وظيفة توزيع المراحل `advanceTripDispatch` تعمل كل دقيقة وتتطلب Cloud Scheduler.
- موقع العميل لا يُتاح للسائقين الآخرين، وموقع السائق لا يُعرض للعميل إلا للرحلة المسندة النشطة.
- احتساب الأجرة يعتمد على مستند التعريفة `fareConfigs/{cityId}__{serviceType}`.
- هذه التعديلات تحتاج بناءً ونشرًا تجريبيًا قبل اعتبارها جاهزة للإنتاج. لم يتم تنفيذ أي نشر حي ضمن هذا الفرع.
