# نموذج بيانات Firestore

- `users/{uid}`: الاسم ووسائل التواصل والدور الأساسي وبيانات الموافقات.
- `drivers/{uid}`: حالة الاعتماد، التوفر، المدينة، بيانات المركبة ومؤشرات الموقع الحالية.
- `trips/{tripId}`: العميل، الالتقاط والوجهة، نوع الخدمة، الحالة، السائق المسند، السعر وسجل الزمن.
- `trips/{tripId}/events/{eventId}`: سجل أحداث غير قابل للتعديل من تطبيقات المستخدمين.
- `fareConfigs/{configId}`: إعدادات التعريفة التي يديرها المسؤول.
- `financialLedger/{entryId}`: قيود مالية ينشئها الخادم فقط.

تطبيق العميل لا ينشئ الرحلات مباشرة في Firestore؛ يستدعي createTrip. وتطبيق السائق لا يسند الرحلة لنفسه مباشرة؛ يستدعي acceptTrip. قواعد Firestore تمنع الكتابة المباشرة على الرحلات والدفتر المالي.
