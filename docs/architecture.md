# معمارية تاكسي العاصمة

## قبول الرحلة
يوزع الخادم الطلب على السائقين المؤهلين على مراحل. عند القبول تنفذ معاملة ذرية تتحقق أن الرحلة ما زالت في حالة البحث وغير مسندة؛ أول معاملة ناجحة فقط تسند الرحلة.

## الأمان
لا يحق للعميل أو السائق تعديل الأجرة النهائية أو العمولة أو إسناد الرحلة مباشرة. تتم هذه العمليات على الخادم.

## البيئات
Development وStaging وProduction تستخدم مشاريع Firebase منفصلة. لا تضع الأسرار في المستودع.

## الإطلاق
1. Firebase Auth وقواعد Firestore.
2. دورة طلب وقبول واختبار التزامن.
3. GPS والإشعارات والخرائط.
4. لوحة الإدارة والمالية والدعم.
5. إطلاق تجريبي محدود.
