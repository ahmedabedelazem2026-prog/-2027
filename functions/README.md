# Cloud Functions

مسؤوليات الخادم الموثوق:
- إنشاء الرحلات والتحقق من المدخلات.
- توزيع الطلب على السائقين المؤهلين تدريجيًا.
- قبول ذري للرحلة لضمان إسنادها لسائق واحد فقط عبر Firestore transaction.
- حساب الأجرة والعمولة على الخادم.
- تسجيل الأحداث المالية وسجل التدقيق.

لا تُفعّل هذه الوظائف قبل إعداد Firebase وقواعد الأمان والاختبارات.
